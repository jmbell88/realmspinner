**Vocabulary.** *Critical*: crash, data loss, or corrupts a document. *High*: a wrong result
the user will hit, or a promise in the docs the code breaks. *Medium*: a defect with a
workaround, or a hard-invariant violation not yet reachable. *Low*: hardening, consistency,
naming. *Reproduced*: an executable example confirmed it. *Inspected*: follows from the current
code path. *Evidence gap*: release proof is missing from the repository, not a demonstrated
failure.
