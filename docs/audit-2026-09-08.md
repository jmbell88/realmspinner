**Vocabulary.** *Critical*: crash, data loss, or corrupts a document. *High*: a wrong result the
user will hit, or a promise in the docs the code breaks. *Medium*: a defect with a workaround, or a
hard-invariant violation not yet reachable. *Low*: hardening, consistency, naming. *Reproduced*: an
executable example confirmed it (scripts under the run's scratchpad `probes/` directory, run with
`uv run --no-sync python <script>`). *Inspected*: follows from the current code path. *Evidence
gap*: release proof is missing from the repository, not a demonstrated failure.

Probe filenames are numbered in each explorer's discovery order, not by the ids below: the three
`clay-document-*.py` scripts prove clay-04, clay-05 and clay-02 respectively.

**Second-look.** Every High below was re-read by the orchestrator against the working tree, and
every Reproduced High's probe was re-run here (all six reproduced). Dropped during merge: `none`.
Downgraded during merge: the bevel ceiling (High → Medium, clay-03: the op completes correctly, the
