**Vocabulary.** *Critical*: crash, data loss, or corrupts a document. *High*: a wrong result the
user will hit, or a promise in the docs the code breaks. *Medium*: a defect with a workaround, or
a hard-invariant violation not yet reachable. *Low*: hardening, consistency, naming.
*Reproduced*: an executable example confirmed it (scripts under the session scratchpad's
`audit-2026-09-13/probes/`, run with `uv run --no-sync python <script>`). *Inspected*: follows
from the current code path. *Evidence gap*: release proof is missing from the repository, not a
demonstrated failure.

**Second-look.** Every record returned as Critical or High was re-read by the orchestrator
against the working tree, and every *Reproduced* one had its probe re-run (all reproduced again).
Explorers returned 7 Critical and 30 High; the merge settled at 1 and 22.

defaults under `config._home()`, and its `write_bytes(b"")` truncated the user's real
`~/.warlock/models/trellis2-gguf/birefnet.gguf` (882,749,024 bytes, sha256 `10c5dd4d…`) to zero at

re-downloaded (Settings → Models, `engine:trellis_gguf`). The skill's
