before the next installer build. Start with `pipelines-01`, because an upgraded install can
quietly run a stale engine, and with `service-01`/`service-02`, because a reroll or a derive
that spends a full generation to return identical output is invisible to the user.

**Vocabulary.** *Critical*: crash, data loss, or corrupts a document. *High*: a wrong
result the user will hit, or a promise in the docs the code breaks. *Medium*: a defect
with a workaround, or a hard-invariant violation not yet reachable. *Low*: hardening,
consistency, naming. *Reproduced*: an executable example confirmed it (scripts under
`<scratchpad>/audit-2026-09-15/probes/`, named `<slice>-<segment>-NN.py`, run with
`uv run --no-sync python <script>`). *Inspected*: follows from the current code path.
*Evidence gap*: release proof is missing from the repository, not a demonstrated failure.

working tree, and the sixteen that shipped a probe were re-run; all sixteen reproduced. Findings
dropped: none. Findings downgraded:
