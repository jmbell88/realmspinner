# clay-agent-v1 -- the subjects an agent is asked to model in Clay, 2026-09-10
#
# One subject per line: `class | prompt`. Blank lines and `#` lines are ignored.
# Parsed by scripts/campaign_props.read_corpus (the same reader the three image
# corpora beside this one use, reused rather than re-written), and printed by
# scripts/agent_bench.py --serve so a tier-two session is run against this list
# rather than against whatever the operator thought of that morning. Cited by
# docs/measurements/2026-09-10-clay-agent-benchmark-preregistration.md, which
# fixes these subjects and the decision rules *before* any grade exists.
# Editing this file after the grades exist invalidates that pre-registration --
# start a new corpus instead.
#
# THE CLASS IS DIFFICULTY OF CONSTRUCTION, NOT OF RECOGNITION. It says how much
# of Clay's surface the subject cannot be built without, which is the thing
# being measured here -- a chair is `easy` because six boxes is genuinely all it
# needs, not because a chair is a simple object to design.
#
#   easy   -- expressible in primitives, placement and materials alone.
#   medium -- needs at least one of: a boolean, a lathe or sweep profile, an
#             array op, or element-mode selection and a topology op.
#   hard   -- needs a swept or tapered form along a path, which is the class of
#             shape the surface gained most recently and has the least evidence
#             for.
#
# The five subjects are the external reviewer's own, carried over verbatim in
# substance: a chair, a mechanical bracket, a telescope, a curved creature and a
# repeated architectural assembly. They were chosen by somebody who had just
# driven this surface and found it wanting, which is a better basis for a first
# corpus than a list written by the people who built it.
#
# PROMPTS ARE BARE SUBJECT DESCRIPTIONS. There is no template appended, unlike
# the image corpora: what a model is handed here is its whole brief, because the
# brief is part of what is being measured.
